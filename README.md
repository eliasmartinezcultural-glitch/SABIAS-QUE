# ¿Sabías que...? — San Patricio del Chañar

Experiencia web estática de verdadero o falso sobre la historia y la identidad de San Patricio del Chañar, Neuquén. Proyecto de Ocarina Producciones.

## Principios
- Una sola mecánica central: responder VERDADERO o FALSO.
- Explicación inmediata después de cada respuesta.
- Rigor histórico: no publicar afirmaciones sin fuente identificable.
- Interfaz simple, visual, accesible y multidispositivo.
- Sin cuentas, backend, bases de datos ni dependencias externas.

## Estructura
- `index.html`: estructura de la experiencia.
- `styles.css`: identidad visual y adaptación responsive.
- `app.js`: flujo de preguntas, respuestas, progreso y resultado.
- `questions.js`: banco editorial de preguntas.
- `FUENTES.md`: registro de fuentes y criterios editoriales.

## Publicación
Activar GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /(root)**.

## Estado editorial
La primera versión contiene una selección inicial de preguntas con fuentes públicas enlazadas. No representa todavía una investigación exhaustiva de toda la historia local. Las preguntas con datos discutidos o testimoniales quedan fuera hasta ser cotejadas.
